# reelkit — монтаж по папке исходников

Движок детерминированный: ни одного вызова LLM. Решения принимаются по
измерениям (тишина, лица, длительности) и по стилю. Твоя роль — выбрать стиль,
запустить, прочитать предупреждения и показать результат.

## Порядок работы

**1. Посмотри, что в папке, прежде чем собирать.**

```bash
python -m reelkit inspect <папка>
```

Печатает по каждому файлу: вид (`talking_head` / `broll` / `voiceover` /
`music`), долю речи и **причину решения**. Если вид определён неверно —
проблема в материале или в пороге, а не в стиле; не лечи это сменой стиля.

**2. Выбери стиль.**

```bash
python -m reelkit styles
```

- `plain_cuts` — **по умолчанию**. Просто монтаж: без субтитров, значит без
  распознавания речи. Бери его, если пользователь не просил субтитры.
- `museum_archive` — документальный, с субтитрами (нужен блок распознавания).
- `museum_pip` — то же плюс ведущая кружком в углу.
- `circle_talk` — кружок во весь кадр, фон размыт.

**3. Собери.**

```bash
python -m reelkit build <папка> --style <стиль>
```

Добавь `--plan-only`, чтобы получить только `plan.json` и обсудить раскладку
до рендера. Готовое лежит в `output/<имя>/vN/final.mp4`, ссылка `latest`
указывает на свежую версию.

**4. Прочитай предупреждения и перескажи их пользователю.** Движок намеренно
говорит вслух о том, чего не смог: отменённый кружок, нехватка перебивок,
пропущенные субтитры, недоступный детектор лиц. Это не шум — это места, где
результат отличается от задуманного.

## Что важно знать

**Форма материала определяется сама.** Отдельный файл озвучки в папке меняет
всю стратегию: он становится спиной монтажа, а вся картинка уходит под него.
Один длинный дубль — наоборот, сокращается вырезанием собственных пауз. Форма
и причина пишутся в `plan.json`.

**Кружок ставится не везде.** Только там, где лицо крупное и устойчиво
держится в кадре. Если человек ходит по кадру, движок откажет — неподвижный
круг его не удержит. Это правильный отказ, не баг.

**Субтитры — необязательный блок.** `plain_cuts` их не включает и виспер не
вызывает. Если стиль просит субтитры, а блок распознавания не установлен,
ролик соберётся без них с явным сообщением.

**План — это файл.** `plan.json` можно прочитать и поправить руками: номера
кадров, тайминги, источники. Анализ (лица, тишина) — долгая часть, рендер —
дешёвая.

## Чего делать не надо

- Не подбирай стиль «на глаз» под каждый ролик: стиль — это повторяемый вид,
  а не настройка одного видео. Нужен новый вид — заведи файл в `styles/`.
- Не правь Python, чтобы поменять внешний вид. Всё, что влияет на картинку,
  живёт в YAML.
- Не выдавай предупреждения за успех. Если кружок отменён или субтитры
  пропущены — скажи об этом прямо.
