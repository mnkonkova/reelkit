# reelkit

**Кидаешь папку с исходниками — получаешь смонтированный вертикальный ролик.**
Без распознавания речи, без облака, без ключей: нужен только `ffmpeg`.

```bash
python -m reelkit build ./my_footage --style plain_cuts
```

Монтаж решают измерения, а не модель: движок меряет тишину, находит лица
локальным детектором, считает ритм по стилю и собирает таймлайн. **Вызовов
LLM — ноль.** Субтитры — необязательный блок сверху (см. ниже).

## Что он делает

1. **Разбирает папку.** Для каждого файла меряет длительность, долю речи,
   паузы и лицо. Решает, что здесь говорящая голова, что перебивка, что
   озвучка, а что музыка — и пишет, почему так решил.
2. **Определяет форму материала** и выбирает стратегию:

   | форма | что в папке | что делает |
   |---|---|---|
   | `narrated_clips` | клипы, наговорённые в кадр | раскладывает по порядку, звук из самих клипов |
   | `voiceover_plus_broll` | отдельный файл озвучки + картинка | озвучка становится спиной, картинка уходит под неё |
   | `single_take` | один длинный дубль | вырезает его паузы, перебивает остальным материалом |

3. **Строит план** — `plan.json`, обычный текстовый файл: какой кадр, с какой
   секунды, где кружок. Его можно прочитать, поправить и пересобрать, не
   перемеряя материал заново.
4. **Рендерит** 1080×1920 30fps: грейд, переходы, кружки, музыка с дакингом.

## Установка

```bash
git clone https://github.com/mnkonkova/reelkit && cd reelkit
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Нужен `ffmpeg` с `libass` в `PATH`.

### Модель лиц

Детектор лиц — YuNet из [OpenCV Zoo](https://github.com/opencv/opencv_zoo)
(файл ~230 КБ). В репозитории его нет, скачай и положи в
`models/face_detection_yunet.onnx`.

Без него всё соберётся, но движок не отличит говорящего от перебивки и не
поставит кружки — он об этом скажет вслух, а не сделает вид, что людей в кадре
нет.

## Стили

Стиль — один YAML-файл. Поменять вид = поменять файл, добавить вид = добавить
файл. Кода трогать не надо.

```bash
python -m reelkit styles          # что есть в библиотеке
```

| стиль | про что |
|---|---|
| `plain_cuts` | просто монтаж, без распознавания речи — **по умолчанию** |
| `museum_archive` | документальный: тёплый грейд, субтитры фразами |
| `museum_pip` | то же + ведущая кружком в углу поверх перебивки |
| `circle_talk` | кружок во весь кадр, фон размыт (Telegram-стиль) |

Каждый стиль наследует `styles/_base.yaml` и переопределяет только своё.
Неизвестные ключи отвергаются: опечатка `circel:` иначе молча прошла бы мимо,
и ролик вышел бы в дефолтном виде без единой ошибки.

Поля стиля проверяются между собой. Например, кружок, попадающий на строку
субтитров, не загрузится вовсе — геометрия известна до рендера.

## Кружки

```yaml
circle:
  mode: pip          # pip | main | off
  diameter: 0.34     # доля ширины кадра
  center: [0.74, 0.50]
  zoom: 2.2          # сторона квадрата = 2.2 ширины лица: голова и плечи
```

`pip` — голова в углу поверх перебивки, `main` — круг во весь кадр с размытым
фоном. Кружок ставится только там, где лицо реально крупное и устойчивое;
где нет — движок откажет и напишет, почему. В форме `voiceover_plus_broll`
кружки выключаются принудительно: озвучка отдельным файлом, губы в кадре со
звуком не совпадут.

## Субтитры

Единственная часть, которой нужно распознавание речи, — и единственная
необязательная. `captions: {enabled: false}` (как в `plain_cuts`) означает,
что виспер не вызывается вообще.

Чтобы включить, нужен основной движок
[flexi](https://github.com/mnkonkova/flexi-era) рядом — оттуда берутся ASS-рендерер
субтитров, таблица исправлений и `faster-whisper`. Если стиль просит субтитры,
а блока нет, движок скажет об этом и соберёт ролик без них.

## Команды

```bash
python -m reelkit inspect ./footage              # что движок видит и почему
python -m reelkit build ./footage --style plain_cuts
python -m reelkit build ./footage --style museum_pip --plan-only
python -m reelkit preview ./clip.mp4 --style circle_talk   # пара секунд с кружком
```

Рендеры версионируются: `output/<имя>/vN/` и ссылка `latest` на свежий.
