# models/

Сюда кладётся детектор лиц **YuNet** — файл `face_detection_yunet.onnx`
(~230 КБ) из [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet).

Сам файл в репозитории не лежит: это чужая модель со своей лицензией, и
правильнее брать её из первоисточника, а не из копии.

Без неё движок соберёт ролик, но не отличит говорящего от перебивки и не
поставит кружки — он скажет об этом в выводе, а не сделает вид, что людей в
кадре нет.
